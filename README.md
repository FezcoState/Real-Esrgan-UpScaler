# Real-ESRGAN Image Upscaler

A simple Python-based image upscaling tool powered by **Real-ESRGAN**. Enhances the quality and resolution of `input.jpg` using AI-based image processing.

### Usage
Install the required dependencies from `requirements.txt` and run `upscale.py`.

### ⚠️ Disclaimer
This is an old, unmaintained project. Use at your own risk. AI upscaling can put significant load on your GPU, consume substantial VRAM, and cause high temperatures. Your graphics card might not appreciate it. 

**No guarantees, no support, just an old project.**
